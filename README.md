# mod-mc-sans-nom

Mod géopolitique pour Minecraft **1.21.1 / NeoForge** (nom provisoire : `geopoliticsmod`).
Nations joueurs et PNJ, régimes et lois, territoires, économie monétaire, diplomatie, ONU, guerres et espionnage.

Voir [ROADMAP.md](ROADMAP.md) pour l'architecture et les phases de développement.

## Compiler
Il faut un JDK 21.
```
./gradlew build          # le .jar sort dans build/libs/
./gradlew runClient      # lance le jeu de développement
```
